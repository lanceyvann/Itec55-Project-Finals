PitStop OS — Concept & Quick Guide

Story Mode vs. OS Mode Terminology

Both views run the exact same live simulation. Clicking View: Story Mode / OS Mode switches every label, "Why?" explanation, log entry, lifecycle history, and status message between the PitStop workshop and pure OS views.

Story Mode (Tire Workshop) OS Mode (Operating System) What It Represents
Shop Floor / Shop Manager User Mode / Kernel Mode Normal execution vs. privileged manager/kernel actions
Shop Operations Manager OS Kernel Manages jobs, waiting lines, requests, and equipment locks
Active Service Bay CPU Executes 1 active job/process per simulation tick
Vehicle Service Job (Job #) Process (PID) An independent work order with its own ID & burst
Vehicle Service Record PCB (Process Control Block) Stores ID, parent, status, priority, clipboard/registers & history
Mechanic Service Task (Task #) Thread (TCB / TID) Sub-tasks sharing the job's workspace/memory
Bay Waiting Line / Equipment Wait Line Ready Queue / Waiting Queue Waiting lines for service bay dispatch or equipment/I/O
Bay Turn Time Quantum (Q) Max ticks per turn under Round Robin before rotation
Equipment Lock Mutex Lock Exclusive lock on Tire Changer or Wheel Balancer
Service Bay Changeover Context Switch (CS) Switching the bay/CPU from one vehicle/process to another
Shop Gridlock Deadlock 2-job circular wait between Tire Changer & Wheel Balancer
Rush Hour Burst Workload Adds 2–4 predefined fixed-attribute jobs/processes
Shift Replay (Checkpoints) Time Machine (Snapshots) Tick-by-tick state history scrubbing and branching
Checked In / Waiting for Service / Undergoing Tire Service / Waiting for Equipment / Service Completed New / Ready / Running / Waiting / Terminated 5-State Process Lifecycle

Quick Controls & Standout Features

  • Playback, Presets & Rush Hour: Use Start, Pause, or Step (+1 Tick) to compare FCFS, SJF, Round Robin (using Bay Turn / Quantum), and Priority across 3 presets. Click Rush Hour / Burst Workload to spawn 2–4 predefined vehicles/processes with fixed attributes and unique IDs.
  • Reset vs. Load Preset: Click Reset to restore timers, queues, metrics, locks, and the timeline back to Tick 0 while preserving all default and Rush Hour records. Click Load to reload the selected preset from scratch.
  • Full Record CRUD & Hierarchy: Click + Add Vehicle Job / + Add Process to create entries, Edit to modify bursts, priority, or check-in/arrival time, + Child to spawn a linked sub-job/child process, Terminate to halt it, or Delete to remove it.
  • "Why?" Explainer & Shift Replay / Time Machine: Click any timeline/Gantt block to inspect why that job/process was dispatched at that tick, jump straight to its checkpoint/snapshot, scrub past ticks, or click Resume Here to branch.
  • Gridlock / Deadlock Demo & Manual Actions: Click Simulate Gridlock / Run Deadlock Demo to trigger a 2-job circular wait and Resolve to recover, or use + Mechanic Task / createThread(), Finish Task / joinThread(), Request Equipment / requestIO(), and Yield Service Bay / yieldProcess().
  • Benchmarking & Testing Suite: Evaluates FCFS, SJF, Round Robin, and Priority across all 3 workloads using the live execution engine without altering your active session, verifying completion, reproducibility, and metric accuracy with consolidated tables and charts.
